## This is my 1st JAVA Practical.


## Requirements

* Java Development Kit (JDK) 17 or later
* Command Prompt, Terminal, or any Java IDE (VS Code, IntelliJ IDEA, Eclipse)



Open the terminal in the project folder and run:

```bash
javac MiniBank.java
```

## Run

After successful compilation, run:

```bash
java MiniBank
```

## Program Features

The application displays a menu with the following options:

1. Open Account
2. Deposit
3. Withdraw
4. Transfer
5. Exit

Enter the corresponding number to select an option.

## Verification

The program has been tested to ensure that:

* The menu is displayed repeatedly after completing each operation.
* Each menu option executes its corresponding action.
* Invalid menu choices are handled without crashing the program.
* Selecting **EXIT** terminates the program successfully.
